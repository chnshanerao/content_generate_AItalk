# Job Intelligence Suite — 商业化方案

> 产品：Job Radar（岗位雷达）+ Talent Intel（人才情报）
> 版本：v1.0
> 日期：2026-06-09

---

## 一、产品定位

### 一句话定位

**从招聘数据反推公司战略的情报工具。**

不是招聘网站，不是简历工具，而是把公开招聘数据变成**商业情报**的分析引擎。

### 两个产品

| 产品 | 定位 | 核心用户 | 一句话价值 |
|---|---|---|---|
| **Job Radar** | 岗位雷达 | 求职者（高端） | "一键看透任何公司的全部在招岗位，并告诉你哪些最适合你" |
| **Talent Intel** | 人才情报 | VC / 企业战略 / 猎头 | "从招聘数据推断竞对的真实战略方向、商业化阶段和全球化布局" |

### 差异化

| 竞品 | 它做什么 | 我们做什么不同 |
|---|---|---|
| LinkedIn Jobs | 搜索岗位 | 我们**全量拉取**（不受搜索推荐算法限制）+ **画像匹配评分** |
| Glassdoor | 公司评价 + 薪资 | 我们做**战略洞察**（从招聘数据推断公司在赌什么） |
| Theirstack | 从招聘推断技术栈 | 我们不止技术栈，还做**GTM 密度、商业化阶段、全球化布局** |
| LinkedIn Talent Insights | 人才市场报告 | 我们**跨公司对比**（同时分析 4 家竞对），且**实时数据**（不依赖季度报告） |

## 二、目标客户分层

### Tier 1：VC / PE 投资机构（最高付费意愿）

**场景：** 投前尽调 — "这家公司说自己 All-in AI，但招聘数据显示 GTM 占比只有 3%，说明还在技术探索期"

**价值量化：** 一份尽调报告的市场价 ¥5-20 万，我们提供的数据洞察可以替代 1/3 的人工调研工作量

**定价承受力：** ¥2,000-8,000/份报告 或 ¥5,000-20,000/月订阅

**示例客户画像：**
- 红杉/高瓴/GGV 的投资经理
- 关注 AI 赛道的 FA
- 二级市场 AI 行业研究员（如评估智谱的上市估值）

### Tier 2：企业战略 / 竞品分析部门

**场景：** "字节本周新增了 15 个 Ads 岗位 → OpenAI 正在进入广告市场 → 我们需要调整定价策略"

**价值量化：** 竞对情报的时效性直接影响决策质量。传统方式（手动翻招聘网站）每周需要 2-3 小时，我们 5 分钟自动完成。

**定价承受力：** ¥1,000-5,000/月订阅

### Tier 3：猎头 / 招聘机构

**场景：** 批量获取目标公司全量岗位 → 推断组织架构 → 找到隐藏的岗位需求

**定价承受力：** ¥500-2,000/月

### Tier 4：高端求职者（引流层）

**场景：** "帮我看看 OpenAI 有什么适合我的岗位"

**定价承受力：** ¥50-200/次（或免费引流 → 转化到 Tier 1-3）

## 四、GTM 策略（Go-To-Market）

### Phase 1：种子用户（第 1-4 周）

1. **在自己圈子里推** — 把 Job Radar 分享给身边的求职朋友，收集反馈
2. **LinkedIn 发帖** — "我用 AI 工具 5 分钟爬完了 OpenAI 721 个岗位并分析了它的战略方向，发现 GTM 是它最大的部门..."（用洞察引流）
3. **VC 朋友试用** — 免费提供 2-3 份 Talent Intel 报告，换取推荐和反馈

**目标：** 10 个活跃用户 + 3 个付费用户

### Phase 2：验证 PMF（第 5-12 周）

1. **知识星球 / 小报童** — 发布每周 AI 招聘情报（"本周 OpenAI 新增 23 个岗位，其中 Ads 方向 +8，首次出现 Robotics 岗位"）
2. **即刻 / Twitter** — 定期发布洞察图表（城市分布图、技术栈热力图）
3. **合作猎头** — 找 2-3 家 AI 方向猎头合作，按推荐成功付费

**目标：** 30 个付费用户 + MRR ¥5,000

### Phase 3：规模化（第 13-24 周）

1. **产品化** — 从 Skill 升级为 SaaS Dashboard（Streamlit / Next.js）
2. **覆盖扩展** — 从 AI 公司扩展到整个科技行业（100+ 公司）
3. **自动化** — 每周自动爬取 + 推送变化报告 + 钉钉/飞书/邮件通知

**目标：** 100 个付费用户 + MRR ¥30,000

| 竞品 | 融资 | 年收入(估) | 我们的优势 |
|---|---|---|---|
| **Theirstack** | 未公开 | $1-5M | 他们只做技术栈推断，我们做完整的战略洞察（GTM/商业化/全球化） |
| **Revealera** | Seed轮 | <$1M | 他们覆盖面广但洞察浅，我们深度对比+可视化更强 |
| **LiveData Technologies** | $20M+ | $5-10M | 他们聚焦人才流动（谁跳槽了），我们聚焦战略信号（公司在赌什么） |
| **LinkedIn Talent Insights** | N/A | 捆绑销售 | 他们的数据基于 LinkedIn 用户行为，我们直接从招聘 API 拿第一手数据 |
| **Glassdoor/Indeed** | 上市 | $500M+ | 他们做信息聚合，我们做情报分析 |

**护城河：**
1. **API 逆向工程能力** — 我们已经破解了 4 种 ATS 平台的反爬机制，这个知识需要持续维护
2. **洞察模板** — 15+ 维度的战略分析框架（商业化阶段/GTM 密度/Agent 押注等）是领域知识的积累
3. **数据积累** — 长期运行后可以分析趋势变化（"字节 Agent 岗位从 Q1 的 800 个增长到 Q2 的 1,746 个"）

## 八、风险与应对

| 风险 | 严重度 | 应对策略 |
|---|---|---|
| ATS 平台封禁 API | 中 | 控制爬取频率（每周 1 次），使用代理 IP 池 |
| 法律/ToS 风险 | 中 | 只抓取公开可见的招聘信息，不存储个人隐私。参考 HiQ v. LinkedIn 判例（美国法院裁定爬取公开数据合法） |
| API 变更 | 中 | 每周自动测试脚本，变更时快速修复（已有逆向经验，1-2 小时可修复） |
| 竞品跟进 | 低 | 我们的壁垒在洞察层（战略分析框架），不在爬虫层。先发优势 + 数据积累 |

## 九、为什么是现在？

1. **AI 行业进入商业化拐点** — OpenAI/Anthropic/字节的 GTM 部门都在爆发式扩张，对招聘情报的需求是结构性的
2. **AI Agent 让 Skill 分发成为可能** — 不需要建网站/做 App，一个 Skill 包就能触达用户
3. **你的独特优势** — 你在阿里云做销售运营/GTM/竞品分析，这正是 Talent Intel 的目标用户画像。你既是产品的设计者也是典型用户
4. **几乎零成本启动** — 代码已经写好，Skill 已经打包，今天就能开始卖
